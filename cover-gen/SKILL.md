# 炸裂封面生成器 (cover-gen)

## 效果

| 平台 | 尺寸 | 文件命名 |
|------|------|----------|
| B站 (16:9 横版) | 1920×1080 | `01-封面-为什么总被骂？.jpg` |
| 抖音 (3:4 竖版) | 1080×1440 | `01-封面-为什么总被骂？-抖音.jpg` |

设计要素：

- 全屏雷军背景照片（暗角 + 放射爆炸光 + 中心光晕）
- 四角金色 L 形装饰 + 小金点（优雅）
- 大黄字 + 粗黑描边（炸裂） — 中文适配自动计算字号
- 橙红中字 + 金黄小字
- 字号根据文字长度自动缩放，确保在 4:3/全屏安全区内不溢出
- 底部发光渐变光带

## 安装

```bash
pip install playwright
playwright install chromium
```

## 使用

```bash
# 同时出两套（默认）
python generate_covers.py

# 仅 B站 16:9 横版
python generate_covers.py --landscape

# 仅 抖音 3:4 竖版
python generate_covers.py --portrait
```

## 自定义文案

修改 `generate_covers.py` 里的 `COVERS` 数组即可：

```python
COVERS = [
    {
        "id": "01",
        "big": "为什么总被骂？",     # 大字（黄色），自动计算字号
        "mid": "爱恨同源",           # 中字（橙红色）
        "sub": "容错率≈0 · 全网都在骂是幻觉？",  # 小字（金黄色）
        "badge": "5个真相",          # 标签
        "bg": "#1a0000",             # 底色（照片没加载时的备用色）
        "glow": "#ff2200",           # 光效主色调
    },
    ...
]
```

## 照片

脚本自动扫描 `assets/leijun_photos/` 和 `assets/leijun_photos2/`，按文件大小选用最大的那张。若要换照片，直接替换/添加图片到这两个目录。

## 字号算法（核心）

两种比例的安全宽度不同：

| 模式 | 安全宽度 | 原因 |
|------|----------|------|
| B站 16:9 横版 | **1420px** | B站小封面是 4:3 居中裁剪(1440×1080)，文字要在裁剪区内 |
| 抖音 3:4 竖版 | **画布宽-60px** | 竖版无后续裁剪，全可见 |

每行文字的字号：
- 大字：`max(140px, min(220px, 安全宽度 ÷ 字数))`
- 中字：`max(80px, min(140px, 安全宽度 ÷ 字数))`
- 小字：`max(30px, min(55px, 安全宽度 ÷ 字数))`
- 若有剩余空间则增加字距，否则收紧

**效果示例：**
- "为什么总被骂？" (7字) → B站 横版 202px / 抖音 竖版 145px
- "穿啥都被骂" (5字) → B站 横版 220px / 抖音 竖版 204px
- "手机能蒙" (4字)   → B站 横版 220px / 抖音 竖版 220px
